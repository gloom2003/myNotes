# bug的修复程度与优先级问题

1.修复bug时，不需要弄到最好，不然会很费时间，做到可以接受就行，把时间留去排查bug、摸鱼和处理一些不能够接受的bug（优先级高的bug）
2.排序bug的优先级时，直接在优先级那里写好，用确定了就不能改的打算来排，不然后面bug的调整也费时间

3.如果bug是防小人相关的（正常操作是没问题的）、可以通过一些方式规避的，那可以先不进行修复，因为每一个bug要修复好都比较耗费时间，没必要花太多时间在这些问题上面，而且可见性低，后面有这个要求时再修即可
