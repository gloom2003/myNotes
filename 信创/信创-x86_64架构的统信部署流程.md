# x86_64 的统信 UOS 桌面系统部署流程

### 总体思路先说清楚

你要做的事可以拆成 3 大块：

1. 在虚拟机里装好 **x86_64 的统信 UOS 桌面系统**。  
2. 在 UOS 里装好 **Qt 开发环境 + VLC 开发包**。  
3. 把现在的 `desktopApp` 工程拷进去，用 Qt Creator 打开 `desktopApp.pro`，稍微改下 VLC 路径，然后 **编译 + 运行**。

下面给你一个可以几乎照着做的清单，按顺序一步一步来就行。

---

## 一、在虚拟机安装 x86_64 统信 UOS

### 1. 准备镜像和虚拟机

- **下载 UOS x86_64 桌面版镜像**（试用版/个人版都可以，只要是 64 位、带桌面的）。  
- 本机装一个虚拟机软件：VMware / VirtualBox / Hyper‑V 任意一个。  
- 新建虚拟机时：
  - CPU：2 核以上；
  - 内存：4GB 起步（能给 8GB 更好）；
  - 磁盘：至少 40GB；
  - 网卡：NAT 或桥接都行（能上网就行）。

### 2. 安装 UOS

- 虚拟机挂载 UOS 的 ISO，按安装向导一路下一步安装。  
- 建议安装时勾选“**桌面环境/常用软件**”，这样自带图形界面和一些开发工具。

---

## 二、在 UOS 里准备开发环境（Qt + VLC）

后面所有命令都在 **UOS 虚拟机里打开“终端”** 执行。

> 注意：UOS 底层是 Linux，但用的不是纯 Ubuntu，那些包名可能有出入，下面命令是“参考模板”，你可以按提示在应用商店里搜索同名软件。

### 1. 更新软件源 & 基础工具

```bash
sudo apt update
sudo apt install build-essential git
```

如果系统提示不是 `apt` 而是别的（比如 `apt-get` 或图形化软件中心），按系统提示来即可，核心目标是：**装上 gcc/g++ 这套编译工具链**。

### 2. 安装 Qt 和 Qt Creator

有两种方式，你任选一种：

- **方式 A：通过 UOS 软件商店**  
  - 打开“应用商店 / 软件中心”；  
  - 搜索 `Qt Creator`，安装；  
  - 一般会把基础 Qt 运行库一起装上。

- **方式 B：用命令行装开发包（更标准一点）**

参考命令（实际包名可能略有不同）：

```bash
sudo apt install qtcreator \
                 qtbase5-dev \
                 qtdeclarative5-dev \
                 qtwebengine5-dev \
                 qtwebchannel5-dev \
                 qtmultimedia5-dev
```

核心是：**必须有 webenginewidgets + webchannel 这两个模块**，因为你 `.pro` 里写了：

```text
QT += core gui webenginewidgets webchannel
```

如果安装时提示某个包名不存在，你可以：

- 在软件中心里搜 `qt5` / `webengine` / `webchannel`，看官方提供的包叫什么；
- 或者在终端里用 `apt search webengine` 之类命令搜索相近名字。

### 3. 安装 VLC 播放库开发包

你 `.pro` 里引用了 VLC：

```text
VLC_INCLUDE_PATH = $$PWD/../vlc-3.0.8/sdk/include
VLC_LIB_PATH = $$PWD/../vlc-3.0.8/sdk/lib

INCLUDEPATH += $$VLC_INCLUDE_PATH

LIBS += -L$$VLC_LIB_PATH \
        -llibvlc -llibvlccore
```

在 Linux 下，建议直接用系统自带的 VLC 开发包：

```bash
sudo apt install vlc libvlc-dev libvlccore-dev
```

安装成功后，一般会有：

- 头文件在：`/usr/include/vlc`  
- 动态库在：`/usr/lib/...` 或 `/usr/lib/x86_64-linux-gnu/...`

这些路径，后面要写回 `.pro` 里。

## 三、把工程拷到 UOS 里

### 1. 在 Windows 打包你的工程

在 Windows 上，把这个目录压成 zip：

- `SafetyLinkNovo/SafetyLinkNovo/DoorSysPlatform/desktop-client/`

确保里面至少包含：

- `desktopApp/`（Qt C++ 工程）
- `html5/`（Vue 前端工程，已经有 `web.qrc` 引用打包好的资源即可）

### 2. 拷贝到 UOS

几种方式任选：

- 通过虚拟机的“共享文件夹”功能；  
- 用 U 盘（需要在 UOS 中挂载）；  
- 用 SCP/FTP 等从 Windows 传到 UOS（稍微麻烦一点）。

在 UOS 里把它解压到你的用户目录，比如：

```bash
cd ~
unzip desktop-client.zip   # 具体名字按你压缩包来
```

假设现在路径类似：

```text
~/desktop-client/desktopApp/desktopApp.pro
~/desktop-client/html5/...
```

## 四、在 UOS 里用 Qt Creator 打开工程

### 1. 启动 Qt Creator

- 在 UOS 菜单里找到 `Qt Creator`，点开。  
- `File -> Open File or Project`，选择：

  `~/desktop-client/desktopApp/desktopApp.pro`

- Qt Creator 会弹出一个向导，让你选择构建 kit（一般会自动选中一个 GCC + Qt 5 的 kit），一路 Next/Finish。

### 2. 先不改代码，直接尝试“分析构建”

- 左侧选中 `Projects` → 确认 kit 使用的是 **桌面 x86_64 + Qt 5.x**。  
- 点击“锤子”图标（构建），看控制台报错内容。

大概率第一轮会遇到的是：

- `jsonconfig.cpp` 等源文件都能找到；  
- 如果 VLC 路径不对，会报“找不到 vlc/vlc.h”之类；  
- 或者如果 Qt WebEngine 包没装好，会报找不到 `Qt5WebEngineWidgets`。

下面重点说 VLC 路径这块如何改。

## 五、针对 Linux/UOS 调整 `desktopApp.pro`（VLC 路径）

你现在 `.pro` 里：

```text
VLC_INCLUDE_PATH = $$PWD/../vlc-3.0.8/sdk/include
VLC_LIB_PATH = $$PWD/../vlc-3.0.8/sdk/lib
```

这是你在 Windows 下本地放的 SDK 路径，UOS 上肯定没有。  
比较典型的做法是：**在 unix 条件编译块里覆盖一下路径**，让 Linux 使用系统自带的 VLC。

你可以在 `.pro` 里改成类似下面这样（这是一个“建议版本”，在 UOS 里手动修改）：

```pro
# 现有内容保留
VLC_INCLUDE_PATH = $$PWD/../vlc-3.0.8/sdk/include
VLC_LIB_PATH = $$PWD/../vlc-3.0.8/sdk/lib

INCLUDEPATH += $$VLC_INCLUDE_PATH

LIBS += -L$$VLC_LIB_PATH \
        -llibvlc -llibvlccore

# 平台特定配置
unix {
    # 覆盖为 Linux 下系统安装的 VLC 路径
    VLC_INCLUDE_PATH = /usr/include/vlc
    VLC_LIB_PATH = /usr/lib

    INCLUDEPATH += $$VLC_INCLUDE_PATH
    LIBS -= -L$$PWD/../vlc-3.0.8/sdk/lib
    LIBS += -L$$VLC_LIB_PATH -lvlc -lvlccore

    contains(QT_CONFIG, xcb): {
        LIBS += -lX11
    }
}

macx {
    LIBS += -framework Cocoa
}

win32 {
    LIBS += -lws2_32
    RC_ICONS = logo.ico
}
```

说明：

- Windows 下还是走你原来的 `../vlc-3.0.8/sdk`；  
- `unix { ... }` 只在 UOS 这种 Linux 下生效，  
  - 把 `VLC_INCLUDE_PATH` 改成 `/usr/include/vlc`；  
  - 把 `LIBS` 从 `-llibvlc -llibvlccore` 调整为系统常用的 `-lvlc -lvlccore`（大小写也按系统实际为准）；  
  - 如果构建时提示库找不到，你可以：  
    - 用 `ls /usr/lib | grep vlc` 看看真实名字；  
    - 或者用 `ldconfig -p | grep vlc` 查已安装的库名。

你不一定要一字不差照抄，但思路就是：**在 unix 块里单独为 Linux 配置 include 路径和库路径**。

## 六、编译并运行 Qt 程序

### 1. 在 Qt Creator 里重新构建

- 保存 `.pro`。  
- Qt Creator 左下选择 `Release` 或 `Debug`。  
- 点击“锤子”构建。  

如果还有报错：

- 报 **找不到某个 Qt 模块**：说明你缺对应的 `qtxxx5-dev` 包，再用 `apt` 装一下；
- 报 **找不到 vlc 头文件或库**：检查你在 `.pro` 里写的路径和 `apt` 实际安装的路径是否一致。

### 2. 运行

构建成功后：

- 点击 Qt Creator 里的“绿色三角形”（Run）。  
- 如果一切顺利，会弹出你的 Qt 窗口，里面通过 `QWebEngineView` 加载 `web.qrc` 里打包的前端页面，`main.js` 会在页面加载完后尝试初始化 QWebChannel。

因为你在 `main.js` 里对 `window.qt.webChannelTransport` 做了检查：

```js
if (window.qt && window.qt.webChannelTransport) {
  new window.QWebChannel(qt.webChannelTransport, async (channel) => {
    ...
  });
} else {
  console.error('QWebChannel init failed: cannot find qt.webChannelTransport');
  // 直接初始化,使用BUSINESS_CONFIG文件中的配置
  await initServices();
  appInitResolver();
}
```

所以：

- 在 **有 QWebChannel 的情况**：会通过 C++ 端的 `myChannel` 加载配置；  
- 在 **找不到 QWebChannel 的情况**：还会用 `BUSINESS_CONFIG` 做兜底，你至少能看到前端 UI 跑起来。

## 七、你可以按这个顺序一步步走

最后帮你整理成一个“超简版待办清单”，你可以勾一项做一项：

- **[ ]** 虚拟机里安装 x86_64 统信 UOS 桌面版，并能正常进桌面、上网。  
- **[ ]** 在 UOS 安装：`gcc/g++`、`Qt Creator`、`Qt 5 WebEngine + WebChannel`、`VLC 开发包`。  
- **[ ]** 把 `desktop-client` 目录从 Windows 拷到 UOS（家目录下即可）。  
- **[ ]** Qt Creator 打开 `desktopApp.pro`，生成 Linux 桌面 kit 的构建配置。  
- **[ ]** 在 `.pro` 中为 `unix {}` 配置正确的 `VLC_INCLUDE_PATH` 和 `VLC_LIB_PATH`（对应 `/usr/include/vlc` 和 `/usr/lib`）。  
- **[ ]** 编译（构建），解决缺包/路径问题，直到构建成功。  
- **[ ]** 运行程序，确认 Qt 窗口能起来，前端能加载，日志中没有致命错误。
